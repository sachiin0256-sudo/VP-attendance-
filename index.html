Privacy and security model

  • No central face-photo or face-template database in this MVP.
  • Authentication is handled by Supabase Auth; use strong passwords and MFA.
  • Attendance writes go through an Edge Function using the authenticated user and server time.
  • Admin role is assigned manually by a trusted database administrator, never by public sign-up.
  • Production deployment still requires security testing, backups, retention rules, employee notice and applicable legal review.
